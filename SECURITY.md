# Kebijakan keamanan SIPADI

Jangan membuka detail kerentanan pada issue publik. Laporkan secara privat kepada penanggung jawab keamanan organisasi dengan subjek `SIPADI Security`, meliputi versi/URL terdampak, langkah reproduksi aman, dampak, dan bukti yang telah disanitasi.

Kontak keamanan produksi wajib diisi sebelum go-live:

- Security lead: `[nama / telepon / email]`
- Incident commander: `[nama / telepon / email]`
- Infrastruktur/on-call: `[nama / telepon / email]`
- Pemilik data/DPO: `[nama / telepon / email]`

Jangan mengirim password, token, kunci enkripsi, recovery code, data pribadi, atau arsip asli melalui email/tiket. Gunakan kanal transfer terenkripsi yang disetujui organisasi.

Target respons internal yang disarankan: acknowledgement laporan kritis dalam 4 jam kerja, triase dalam 1 hari kerja, dan pembaruan berkala sampai mitigasi selesai. Tenggat final ditetapkan berdasarkan tingkat risiko dan kebijakan instansi.
