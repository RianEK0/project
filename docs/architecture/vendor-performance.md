# Vendor Performance Foundation

Sprint 3C menambahkan starter read model untuk performa vendor.

## Signals

- on-time receipt rate,
- average lead time,
- price variance terhadap quotation,
- acceptance rate receipt,
- vendor rating level,
- lead time trend.

## Sources

- supplier quotation,
- purchase order,
- goods receipt,
- invoice preparation exceptions.

## Purpose

- membantu vendor comparison,
- membantu buyer menentukan supplier repeat order,
- menyediakan sinyal untuk purchase analytics.
