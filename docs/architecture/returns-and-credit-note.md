# Returns and Credit Note Foundation

## Sales Return

Sales return menangani barang kembali dari customer.

Status utama:

- `REQUESTED`
- `APPROVED`
- `INBOUND_PENDING`
- `RECEIVED`
- `INSPECTED`
- `CREDIT_ISSUED`
- `REFUNDED`
- `CLOSED`
- `REJECTED`
- `CANCELLED`

## Credit Note

Credit note menjadi dokumen koreksi komersial sesudah return atau invoice adjustment.

Status utama:

- `DRAFT`
- `PENDING_APPROVAL`
- `APPROVED`
- `ISSUED`
- `APPLIED`
- `VOID`
- `CANCELLED`
