# Delivery and Shipment Foundation

## Delivery Order

Delivery order menyiapkan otorisasi fulfillment per order.

Status utama:

- `DRAFT`
- `READY_TO_PICK`
- `PICKING`
- `PACKED`
- `DISPATCHED`
- `PARTIALLY_DELIVERED`
- `DELIVERED`
- `CANCELLED`

## Shipment

Shipment mewakili perjalanan fisik barang ke customer.

Status utama:

- `PLANNED`
- `READY`
- `IN_TRANSIT`
- `DELIVERED`
- `FAILED`
- `RETURNED`
- `CANCELLED`
