# Warehouse Scanning

Warehouse scanning Sprint 3B menyediakan `ScanSession` dan `ScanEvent` untuk flow putaway, picking, dispatch, count, dan resolve barcode.

## Scan Types

- product,
- variant,
- barcode,
- serial,
- lot,
- warehouse,
- storage location,
- document,
- package.

Data perangkat dijaga minimum dan tidak menyimpan informasi sensitif berlebihan.
