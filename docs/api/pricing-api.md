# Pricing API

## Preview

- `POST /api/v1/pricing/preview`
- `POST /api/v1/services/:serviceId/price-preview`

## Price Rules

- `POST /api/v1/price-rules`
- `GET /api/v1/price-rules`
- `GET /api/v1/price-rules/:priceRuleId`
- `PATCH /api/v1/price-rules/:priceRuleId`
- `DELETE /api/v1/price-rules/:priceRuleId`

## Promotions

- `POST /api/v1/promotions`
- `GET /api/v1/promotions`
- `POST /api/v1/promotions/validate`
