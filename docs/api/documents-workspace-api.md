# Documents Workspace API

## Overview

Documents workspace API memberikan foundation response dan preview response untuk file enterprise, business records, dan governed knowledge yang mencakup format handling, record traceability, dan governance readiness.

## Endpoints

- `GET /api/v1/documents-workspace`
- `GET /api/v1/documents-workspace/formats-preview`
- `GET /api/v1/documents-workspace/records-preview`
- `GET /api/v1/documents-workspace/governance-preview`
