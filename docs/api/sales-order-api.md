# Sales Order API

## Endpoints

- `POST /api/v1/sales-orders`
- `GET /api/v1/sales-orders`
- `GET /api/v1/sales-orders/:orderId`
- `PATCH /api/v1/sales-orders/:orderId`
- `POST /api/v1/sales-orders/:orderId/submit`
- `POST /api/v1/sales-orders/:orderId/approve`
- `POST /api/v1/sales-orders/:orderId/cancel`
- `GET /api/v1/sales-orders/metadata`
