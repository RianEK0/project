# Mobile Workspace API

## Overview

Mobile workspace API memberikan foundation response dan preview response untuk kesiapan PWA, offline sync, dan warehouse mobile surface.

## Endpoints

- `GET /api/v1/mobile-workspace`
- `GET /api/v1/mobile-workspace/pwa-preview`
- `GET /api/v1/mobile-workspace/offline-sync-preview`
- `GET /api/v1/mobile-workspace/warehouse-ui-preview`

## Related Existing Endpoints

- `GET /api/v1/scan/metadata`
- `GET /api/v1/scan/resolve/:code`
- `GET /api/v1/warehouse-tasks/workload`
- `GET /api/v1/portal-notifications`
