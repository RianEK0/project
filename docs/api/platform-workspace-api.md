# Platform Workspace API

## Overview

Platform workspace API memberikan foundation response dan preview response untuk enterprise control plane yang mencakup topology tenant, tenant experience, identity trust readiness, no-code form builder, low-code app builder, hyperscale rollout, enterprise cloud, DevOps platform, enterprise security, plugin marketplace, public API, dan NovaOS program.
