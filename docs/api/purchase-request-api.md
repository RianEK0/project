# Purchase Request API

## Endpoints

- `POST /api/v1/purchase-requests`
- `GET /api/v1/purchase-requests`
- `GET /api/v1/purchase-requests/:requestId`
- `PATCH /api/v1/purchase-requests/:requestId`
- `POST /api/v1/purchase-requests/:requestId/submit`
- `POST /api/v1/purchase-requests/:requestId/approve`
- `POST /api/v1/purchase-requests/:requestId/reject`
- `POST /api/v1/purchase-requests/:requestId/cancel`
- `GET /api/v1/purchase-requests/metadata`
