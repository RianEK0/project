# Opening Balance API

## Core Endpoints

- `POST /api/v1/inventory-opening-balances`
- `GET /api/v1/inventory-opening-balances`
- `GET /api/v1/inventory-opening-balances/:openingBalanceId`
- `PATCH /api/v1/inventory-opening-balances/:openingBalanceId`
- `DELETE /api/v1/inventory-opening-balances/:openingBalanceId`

## Actions

- `POST /api/v1/inventory-opening-balances/:openingBalanceId/items`
- `POST /api/v1/inventory-opening-balances/:openingBalanceId/validate`
- `POST /api/v1/inventory-opening-balances/:openingBalanceId/post`
- `POST /api/v1/inventory-opening-balances/:openingBalanceId/cancel`
