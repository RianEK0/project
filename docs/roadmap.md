# NovaERP Delivery Roadmap

## Stage 1

- Selesaikan monorepo scaffold
- Tetapkan architecture decision awal
- Definisikan bounded modules

## Stage 2

- Matangkan Prisma schema
- Tambahkan migration dan seed
- Siapkan sample tenant, role, dan permission catalog

## Stage 3

- Implement auth API end-to-end
- Tambahkan guards, decorators, audit hooks
- Integrasikan email dan OTP flow

## Stage 4

- Bangun dashboard shell
- Role-aware navigation
- Widget layout dan quick action

## Stage 5

- Booking + CRM + Sales/Order-to-Cash + Customer Portal + Finance/Accounting + HR/People Operations + Manufacturing/Production + AI/Intelligence + Workflow Automation + Integrations + Executive/Domain Dashboards + Mobile/PWA/Device + Platform/Enterprise Admin + Warehouse + Procurement sebagai vertical slices pertama
- Reporting baseline
- Notification hooks

## Stage 6

- Test automation
- CI/CD
- Docker image
- Production deployment guide
